Lộ trình Web Front-end Developer

Thời gian dự kiến: 4-6 tháng. Học từ HTML/CSS đến JavaScript nâng cao, làm chủ ReactJS hoặc VueJS và tối ưu hóa UI/UX.

Lộ trình Backend Developer

Thời gian dự kiến: 6 tháng. Tập trung xây dựng API, làm việc với Cơ sở dữ liệu (SQL, NoSQL), bảo mật phân quyền với Node.js, Java hoặc Python.

Lộ trình Khoa học dữ liệu & AI

Thời gian dự kiến: 8 tháng. Học toán chuyên ngành, lập trình chuyên sâu Python, thư viện Pandas, Machine Learning và Deep Learning.
